# ORBIT 1.0.0 — protected private release candidate

Status: prepared, **not published to Production**. Release date is not assigned.
This candidate preserves the six-window spatial scrapbook and private single-owner
cloud workflow; it does not enable public viewing or add a new product feature.

## Included

- Existing radial task/branch world, timeline, milestones, active/completed rails,
  movable/resizable widgets, dated formatted journal, CSV and V6 JSON backups.
- Protected password sign-in, server UUID ownership, restrictive private-table
  RLS, snapshot persistence, revision conflicts and explicit draft recovery.
- M2.5 interruptible cameras, runtime reduced motion, time-based elastic settling
  and continuous pinch-to-pan, preserving layout, anchors and existing timing.
- M3 fail-closed Production build configuration and reviewed target/CSP validation;
  artifact verification rejects local-mode builds, unexpected files, symlinks,
  native-source drift and an SDK bundle that differs from its locked-source build.

## Preserved limitations

Password-based private use is the supported release scope. OTP delivery, Google
OAuth, physical Safari/Android, physical 120Hz measurements and provider-outage
variants are not newly certified. Session Auth uses sessionStorage; unsaved drafts
must be exported before closing/discarding a session. Backups are unencrypted.
Focus/polling synchronization detects conflicts; it does not automatically merge.

Hosted nonowner read isolation passed 10/10 per owner evidence. Hosted write/CRUD
authorization remains unverified; local SQL/Auth/API results do not prove deployed
write policies. A safe fixture plan is prepared but has not run remotely.

The owner reviewed shared project `ixfgavgtwuzdgucjriec` for `https://orbit.starscene.com/`.
A narrow guard exception permits this pair only. Multi-user Issue #4 is outside M3.
Production remains gated on verified Production-scoped cloud
variables and CSP, Auth redirects, access protection, appropriate owner/nonowner
validation, backup/rollback evidence and final-commit CI. No merge, schema change,
Auth/RLS change, DNS change or blind Preview promotion is implied by version 1.0.0.
