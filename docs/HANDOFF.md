# ORBIT V6 — AUTHORITATIVE NEW-CHAT HANDOFF

**Updated 2026-11-01.** This file is the project's source of truth and supersedes V5 handoff guidance where changed. ORBIT is a private personal **spatial scrapbook**, eventually deployed through private GitHub → Vercel → Supabase Auth + Row Level Security. User loves open, colorful, animated light ambience, translucent liquid-glass-like widgets, a radial elastic constellation with no fixed hierarchy, free-standing terminal task text, timeline, paper diary, a real Just Because branch, and desktop + mobile support. No tabs, conventional dashboards or mandatory productivity scores.

## Binding design requirements

1. **ONE continuous coordinate plane.** Timeline, constellation, active tasks, completed tasks, backup/summary, and journal all float in the same scrapbook space, not grid or scroll sections. Board zoom/pan is separate from constellation's internal camera. Widgets preserve position AND size; drag any unused part of their **header/title** (not just six-dot grip) like a desktop window. Resize using lower-right corner or accessible arrow keys. Dragging empty world moves the world. Keep in-world content controls interactive.
2. **TIMELINE MUST NOT CROP ITS OWN MARKERS.** Deadline markers occupy the upper lane, the axis is below them, milestone names are below the axis, and journal-page links appear **below the milestones**. Maintain minimum usable timeline height as widgets are resized. Journal markers represent one date per chip, with a count for multiple pages. Clicking a marker jumps to the corresponding journal entry within the floating journal, without navigating away from scrapbook. Timeline date domain expands to include older/newer entries.
3. **DATED JOURNAL PAGES.** `JournalEntry.date` is canonical date-only `YYYY-MM-DD` (older ISO-formatted V5 dates normalized using Asia/Jakarta time). A visible native date field on the paper lets the user change it. Edited dates update timeline markers on save. Blank pages do not create markers until given title/body. Markdown export and rich-text autosave remain, with sanitization. Page deletion supports Undo. All entries in JSON backup.
4. **MOBILE NAV MUST NOT OBSCURE WRITING.** On narrow viewports the spatial map appears as one 50px glass compass; tapping expands the miniature map temporarily, and choosing a destination collapses it. True mobile device behavior still requires hands-on verification.
5. **Constellation:** hierarchy is any-depth branch graph, root HISYAM, no card boxes around tasks. Tasks sort/color by urgency or deadline; click/hover expands inline criteria. Completed tasks leave constellation and appear in completed widget and timeline. Idle graph movement subdued, reduced-motion respects settings.
6. **Background:** independently written animated blurred pastel layers. Do not copy AGPL-3.0 Spicy Lyrics implementation. All text and controls must remain legible; reduced transparency and contrast have fallbacks.
7. **Privacy and recovery:** current phase is dependency-free static prototype with localStorage. It does NOT authenticate, encrypt or sync. Export JSON backup; do not publish private journal entries or secrets. Production needs Supabase Auth, owner RLS, private hosting protections, and testing.

## Code map and state

- `src/board.js`: `SpatialBoard`, global camera, title-bar drag, resize pointer/keyboard, `orbit.v5.spatial-layout` position key retained for backward compatibility, NEW `orbit.v6.spatial-sizes` key. `getLayout()` returns per-widget `{x,y,width?,height?}`; `setLayout()` accepts V5 position-only backups and V6 richer data. `buildNavigator()` uses live dimensions.
- `src/widgets.js`: `ScrapWidgets` renders tasks, milestones, deadline and journal timeline markers. `setJournalEntries(entries)` refreshes journal markers; `onOpenJournal(entryId)` selects paper and focuses widget.
- `src/journal.js`: `Journal` constructor accepts `onEntriesChange`; saves titles, HTML and **editable date-only keys**; `openEntry(entryId)` lets timeline select specific page. V5 ISO date compatibility; allows duplicate dates but groups markers.
- `src/app.js`: wires cross-widget callbacks; full JSON backup now **version 6**; restore V5 or V6.
- `index.html`: dated journal input, window headers, mobile navigator toggle. Resize corner is injected into each widget by `board.js`.
- `src/styles.css`: V5 baseline plus V6 overrides, including milestone bounds and flex paper sizing. A future refactor into component CSS should preserve behavior.
- `ORBIT_Offline_Preview.html`: generated by `python scripts_build_preview.py`, available without installing dependencies.
- `docs/DEPLOY.md`: forthcoming deployment instructions and privacy warnings.

## Remaining limitations / next phase

- **No automatic widget collision avoidance when resizing/dragging.** User can intentionally overlap widgets; navigator recovers offscreen ones. Add soft snapping or alignment guides later if requested.
- Milestone delete currently requires clicking twice; consider a safer inline edit control later.
- Browser simulated touch isn't a physical phone; real Safari/Android UI, keyboard safe-area, assistive tech, heavy layouts and deployed HTTPS need testing.
- `execCommand` rich-text formatting is a known prototype compromise. Production should use Tiptap with structured JSON.
- No server database, auth, journal encryption, reminders, external Google sync or collaborative access yet.
- **Next user-requested phase: TRY ONLINE** after user approves V6. Create private GitHub repo and import into Vercel; require explicit user connection/action. Repo privacy ≠ deployed URL protection. Do not demand API keys in chat. Backend and diary sync follow separately.
